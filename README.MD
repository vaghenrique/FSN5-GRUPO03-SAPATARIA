# Projeto Integrador - Capacita Brasil 🧑‍💻🇧🇷
**Equipe 3: Sapataria**  

Bem-vindo ao repositório do nosso Projeto Integrador do programa **Capacita Brasil**! Este projeto tem como objetivo a criação de um **site completo**, refletindo o cenário real do mercado de trabalho, onde frequentemente lidamos com a **manutenção e adaptação de sites existentes**.  

Nosso site será dedicado a uma **sapataria**, oferecendo uma experiência atraente e prática para os usuários.

## 🚀 Objetivo do Projeto  

- Desenvolver um site completo para uma sapataria fictícia utilizando **React, Vite e Bootstrap**.  
- Implementar gerenciamento de estado com **Redux**.  
- Utilizar **Styled Components** para estilização dinâmica e modular.  
- Criar uma interface moderna e responsiva para facilitar a navegação do usuário.  

---

## 📝 Etapas do Projeto  

1. **Configuração do Ambiente**  
   - Criar o projeto com **Vite** e configurar dependências essenciais.  
   - Instalar **React Router, Redux Toolkit, Styled Components e Bootstrap**.  

2. **Estruturação do Repositório**  
   - Configurar o GitHub com branches de desenvolvimento para cada membro da equipe.  

3. **Desenvolvimento do Site**  
   - Implementação das páginas principais:  
     - **Home** (Destaques e novidades)  
     - **Vitrine de Produtos** (Listagem de todos os produtos)  
     - **Carrinho de Compras** (Listagem de pagamento dos produtos comprados)  

4. **Gerenciamento de Estado e Estilização**  
   - Utilização do **Redux** para gerenciar os produtos e estados globais do site.  
   - Aplicar **Styled Components** para criar uma identidade visual moderna e responsiva.  

5. **Entrega Final**  
   - Revisar e testar todas as funcionalidades.  
   - Merge das branches no repositório principal.

## 💡 Tecnologias Utilizadas  

- **React** - Biblioteca para desenvolvimento da interface.  
- **Vite** - Ferramenta de build rápida para React.  
- **Bootstrap** - Framework CSS para estilização responsiva.  
- **Redux Toolkit** - Gerenciamento de estado eficiente.  
- **Styled Components** - Estilização modular e dinâmica.  
- **React Router** - Navegação entre páginas.
